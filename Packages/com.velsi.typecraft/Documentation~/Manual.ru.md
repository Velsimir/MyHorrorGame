# Typecraft — руководство по интерфейсу

[English](Manual.en.md) · Русский

Руководство описывает окно **Typecraft** и работу в нём по задачам: завести строку, перевести,
оформить, подтянуть таблицу из Google Sheets, собрать шрифт, нарисовать диалог. Для кода и
расширения пакета — [`API.ru.md`](API.ru.md), краткая справка — [`README.md`](../README.md).

Скриншоты сняты на демо-сэмпле **Showcase** (раздел [«Демо-сэмпл»](#демо-сэмпл-showcase)):
открой его — и все кнопки и данные из этого руководства будут у тебя под рукой.

## 0. Установка и окно Welcome

1. Положи `com.velsi.typecraft-0.2.0.tgz` в папку `Packages/` проекта.
2. `Window → Package Manager → + → Install package from tarball…` → выбери файл.
3. Дождись перекомпиляции. Typecraft сам поставит TMP Essential Resources, TMPEffects (из копии внутри
   пакета, интернет не нужен) и ресурсы TMPEffects, затем откроет окно **Welcome**.

![Окно Welcome](Images/welcome.png)

- **Обязательно для работы** — ✓ стоит, ✗ нет; у недостающего пункта кнопка «Установить» или
  «Импортировать». Вверху — что поставлено автоматически, идёт ли установка и ошибка, если была.
- **Дополнительно** — Input System (подсказки ввода по биндингам) и Localization (Unity Localization
  как источник строк) ставятся по кнопке.
- **Проект** — «Создать» заводит настройки Typecraft в `Assets/Typecraft`.
- **Быстрый старт** — открыть окно Typecraft, добавить Typecraft Text к выделенному TMP, поставить
  окно диалога в сцену, импортировать сэмпл Showcase.
- **Документация** — руководство и API на выбранном языке, правила арта.
- **RU / EN** — язык окна; галочка внизу — показывать при каждом запуске Unity.

Окно открывается само при первой установке и после обновления версии, вручную —
`Help → Typecraft Welcome` или `Tools → Typecraft → Welcome`.

## 1. Обзор окна

Окно открывается через `Window → Typecraft` (Ctrl+Alt+T) или `Tools/Typecraft/Open Window`.
Вверху — пять вкладок; окно можно пристыковать как обычную вкладку Unity (минимальный размер
420×360, удобно от 1400 px в ширину).

| Вкладка | Для чего |
| --- | --- |
| **✎ Редактор** | Правка разметки одного текста: подсветка, живое превью, галерея стилей, иконок и эффектов |
| **⇄ Локализация** | Таблица «ключ × язык»: перевод, проверки, синхронизация с Google Sheets, Excel и CSV, экспорт |
| **◆ Библиотека** | Наборы иконок, стили, пресеты материалов, свои эффекты |
| **F Шрифты** | Шрифт для каждой роли и языка, покрытие символов, сборка статического шрифта |
| **☰ Диалоги** | Граф диалога, инспектор ноды, проигрывание без запуска игры, проверки |

Что нужно знать до начала:

- **Таблица** хранит слова для переводчика. **Слой разметки** хранит оформление (`[стиль]`, `<тег>`)
  поверх таблицы. Если слова в таблице поменяли, а оформление делалось под старые, оно перестаёт
  применяться и ячейка помечается ⚠. Подробнее — [README → «Слой разметки»](../README.md).
- Окно правит ассеты проекта. Большинство правок можно отменить через Undo (Ctrl+Z); исключения
  оговорены в тексте (переименование стиля или иконки сохраняет сцены и префабы сразу).
- Для живых эффектов (`<wave>`, `<shake>`, машинка) нужен пакет TMPEffects; для глифов кнопок
  `{key:Interact}` — Input System.

## 2. Вкладка «Редактор»

![Вкладка «Редактор»: разметка, превью и галерея](Images/editor-overview.png)

Сверху вниз:

1. **Панель.** Слева — что сейчас правится (`Hint · Showcase/ui.hint [en]` — объект, таблица, ключ,
   язык), замок 🔒 «не переключаться на выделенный объект» и кнопка **Черновик** (свободный
   текст без объекта). Справа — язык превью, устройство (**KBM / Xbox / PS / Switch / Deck / Touch**
   — от него зависят глифы `{key:…}`), ❚❚/▶ — анимация TMPEffects, **машинка** / **Весь** — как
   показывать текст, **метки** — паузы `<!wait>` над текстом, **Применить** (Ctrl+Enter).
2. **Превью** — текст так, как он будет в игре: со стилями, иконками, глифом кнопки и эффектами.
3. **Поле разметки** — текст с подсветкой синтаксиса и подсказками (автодополнение имён стилей, иконок и эффектов по ходу набора).
4. **Галерея** с вкладками **Стили · Материалы · Эффекты · Иконки · Шрифты** — клик по карточке
   вставляет тег (в выделение — оборачивает его).

> **Что правится.** Выдели в сцене объект с `TypecraftText` — окно подхватит его (в режиме
> *Localized* — строку таблицы, в *Inline* — разметку компонента). Для обычного `TMP_Text` есть
> кнопка **→ в таблицу**: она выносит текст в таблицу и переводит объект на ключ. Замок 🔒 держит
> текущий объект, пока ты выделяешь что-то другое.

### Выделение и плавающая панель

![Выделение в поле: плавающая панель стилей, эффектов и иконок](Images/editor-selection.png)

Выдели слово в поле разметки или прямо в превью — над текстом появится плавающая панель:

| Кнопка | Что делает |
| --- | --- |
| **Стиль ▾** | Обернуть выделение в `[стиль]…[/стиль]` (список из библиотеки) |
| **Стиль из выделения** | Забрать теги вокруг выделения (`<color>`, `<b>`, `<i>`, `<u>`, `<cspace>`, `<size>`, эффект) в форму нового стиля |
| **Эффект ▾** | Обернуть в эффект TMPEffects (`<wave>…</wave>`) |
| цветной квадрат | Обернуть в `<color=#…>` |
| **Иконка ▾** | Вставить `{иконка}` из набора |
| **Автотег ▾** | Автоматически оформлять это слово стилем везде |
| **✕** | Снять всю разметку с выделения |

Внизу окна — подпись `Выделено: «light» · 5 симв.`, слева над полем — «чип» стиля, действующего на
выделение (клик по ✕ на чипе снимает стиль).

### Галерея: стили, иконки, эффекты

Вкладки галереи показывают то, что можно вставить.

![Галерея иконок: наборы, ключи и подписи](Images/editor-gallery-icons.png)

![Галерея эффектов TMPEffects](Images/editor-gallery-effects.png)

- **Иконки** — по картинке на карточку, подпись — ключ (`candle`, `key`); в текст вставляется `{ключ}`
  или `{набор/ключ}`.
- **Эффекты** — встроенные анимации TMPEffects и свои (подпись «свой»). Тип показан на карточке:
  постоянный `<x>`, появление `<+x>`, исчезание `<-x>`.
- Карточки **+ стиль**, **+ материал**, **+ эффект** в конце списка открывают формы создания.
- Правый клик по карточке материала или эффекта — удалить (материалы и ассеты эффектов уходят в
  корзину ОС, теги в тексте остаются).

### Задача: создать стиль

![Форма «Новый стиль»](Images/form-style.png)

1. В галерее открой **Стили** и нажми карточку **+ стиль** (или кнопку **+ стиль** во вкладке
   «Библиотека»).
2. Впиши **Id** — имя тега (`danger` → `[danger]текст[/danger]`). Пока Id пуст или занят, под
   формой показана причина, а «Сохранить» недоступно.
3. Задай оформление: **Название** (для списков), **Роль шрифта** и **Пресет материала**, **Свой цвет**
   и **Цвет** (или **Градиент**), **Жирный / Курсив / Подчёркнутый**, **Регистр**, **Размер, %**,
   **Интервал, em**, **Эффект** (кнопка ▾ — список TMPEffects).
4. Справа — живое превью на выделенном тексте или на образце.
5. **Сохранить** добавляет стиль в `StyleLibrary`; если в поле был выделен текст, он оборачивается
   в `[id]…[/id]`. **Отмена** закрывает форму без изменений.

Чтобы собрать стиль из уже расставленных тегов, выдели текст с `<color=…><b>…` и нажми
**Стиль из выделения**: теги переедут в форму, а после «Сохранить» заменятся одним `[id]…[/id]`.

### Задача: создать пресет материала

![Форма «Новый пресет материала»](Images/form-material.png)

Пресет — вариант SDF-материала шрифта: обводка, подложка, свечение.

1. Галерея → **Материалы** → **+ материал**.
2. Выбери **Роль шрифта**, **Имя пресета** и язык для превью.
3. Крути **Face Dilate / Softness**, **Обводка** (цвет, толщина), **Подложка (Underlay)**, **Свечение (Glow)**.
   Свечение есть только в полном шейдере: пресет с ним переведёт материал на `TextMeshPro/Distance Field`.
4. **Сохранить**: пакет создаст копию материала **для каждого шрифта роли** (у каждого языка свой
   атлас) под одним id, поэтому стиль с этим пресетом работает на всех языках.

### Задача: создать свой эффект

![Форма «Новый эффект»](Images/form-effect.png)

1. Галерея → **Эффекты** → **+ эффект**.
2. **Тип**: постоянный, появление или исчезание. **Основа** — копия встроенной анимации
   TMPEffects, `Generic` (дорожки) или `Stack` (несколько анимаций). **Имя тега** — строчные
   латинские буквы, цифры и `_`; имя не должно совпадать со встроенным эффектом или тегом TMP.
3. Параметры основы правятся в блоке «Параметры» (это инспектор ассета).
4. **Сохранить**: эффект попадает в базу анимаций проекта, в автодополнение, галерею, меню
   «Эффект ▾» и список эффектов стиля.

> В превью формы тег с ещё не сохранённым именем виден буквально (`<myeffect>…`) — эффект
> заработает после «Сохранить».

### Задача: записать правку слов в таблицу («было / стало»)

![Окно «Текст локализации изменён»](Images/editor-text-change.png)

Если открыт ключ из таблицы и ты **поменял слова** (а не только оформление), «Применить» не пишет
молча: появляется окно «было / стало». Оно же показывается при уходе на другой объект и при
закрытии окна с неприменёнными словами.

- **Записать в таблицу** — таблица получит новый текст без оформления, слой — оформление.
- **Вернуть слова** — оставить слова таблицы и сохранить только изменения оформления (недоступно,
  если новое оформление нельзя привязать к старым словам; причина указана в окне).
- **Отмена** — вернуться к редактированию.

Если слова не менялись, «Применить» пишет только в слой разметки.

## 3. Вкладка «Локализация»

![Вкладка «Локализация»: сетка ключ × язык](Images/localization-overview.png)

Сетка строк: ключ слева, затем колонка на каждый язык (звёздочка ★ — основной), колонки
**Проблемы** и **Комментарий**.

**Панель.** Источник строк и сводка (`ключей: 19 · с проблемами: 19`), выбор таблицы и кнопки
**+ таблица**, **▸** (показать ассет таблицы), поиск, фильтр, **+ ключ**, **+ язык**,
**Синхронизировать**, **Источник…**, **Импорт…**, **Экспорт…**, **⟳** (перепроверить всё) и язык
**Сцена:** — на каком языке показываются тексты в сцене.

**Фильтры:** *Все строки · Есть проблемы · Только изменившиеся · Нет перевода · Не помещается ·
Нет символа в шрифте · Разметка расходится*.

**Значки в ячейках и в колонке «Проблемы»:**

| Значок | Что значит |
| --- | --- |
| `—` (красный фон) / `∅` | Нет перевода |
| `⇲` | Не помещается (текст длиннее лимита) |
| `□` | В шрифте языка нет символа |
| `≠` | Разметка расходится (токены `{…}` в языках не совпадают) |
| `✦` | Для строки есть оформление в слое разметки |
| `⚠` | Строку в таблице изменили — оформление перестало применяться |

Число после значка (`∅2`) — в скольких языках проблема. Подсказка над ячейкой раскрывает причину.

**Горячие действия по ключу:** двойной клик — где используется, **F2** или правый клик — переименовать.

### Панель ячейки

![Выбранная ячейка: поле, слой разметки и превью](Images/localization-cell.png)

Клик по ячейке открывает панель внизу: слева — поле строки (с подсветкой разметки и подсказками),
справа — превью с реальным шрифтом языка. Кнопки: **Найти в проекте**, **Переименовать**,
**Удалить ключ**; внизу — **Комментарий** для переводчика. Блок **✦ Разметка в слое** показывает,
как строка оформлена, и кнопку **Сбросить разметку**.

### Задача: добавить ключ

![Запрос имени нового ключа](Images/localization-add-key.png)

1. Выбери таблицу в выпадающем списке (нужной таблицы нет — **+ таблица**, имя вроде `UI`,
   `Dialogues`, `Items`).
2. **+ ключ** → впиши имя в стиле `ui.door.locked` → **OK**. Ключ появится в сетке выбранным.
3. Заполни ячейку основного языка (★), затем остальные — см. следующую задачу.

### Задача: перевести строку

1. Кликни ячейку нужного языка в строке ключа — внизу откроется панель.
2. Напиши текст в поле. Правки пишутся в таблицу **сразу** и отменяются Ctrl+Z.
3. Токены, зависящие от порядка слов, ставь прямо в текст: `{key:Interact}`, `{candle}`, `{0}`. Если
   в основном языке есть токен, а в переводе нет (или наоборот), в колонке «Проблемы» появится `≠`.
4. Нужного языка нет в сетке — **+ язык** (код: `en`, `ru`, `zh-Hans`, `ja`, `pt-BR`…).
5. Оформление (`[стиль]`, `<тег>`) в таблицу не пишется — его ставят во вкладке «Редактор» (см.
   выше): таблица остаётся чистой для переводчика.

Языки с иероглифами показывают `□` и «нет N» на вкладке «Шрифты», пока шрифт не пересобран под
новые строки — см. [задачу «Собрать шрифт»](#задача-собрать-шрифт-для-языка).

### Задача: вернуть оформление после правки строки

![Строка изменилась, оформление не применяется](Images/localization-key.png)

Если переводчик (или синхронизация) поменял строку, у которой есть оформление в слое, ячейка
помечается ⚠, а в панели ячейки видно «Было (снимок)» и «Стало (таблица)».

- **Перенести теги** — переставить оформление на новый текст по совпадающим словам. Что нельзя
  привязать точно — покажет и спросит.
- **Сбросить разметку** — удалить запись слоя: строка покажется без оформления.
- Фильтр **Только изменившиеся** собирает все такие строки.

### Задача: где используется ключ

![Список мест использования ключа](Images/localization-usages.png)

Двойной клик по ключу (или **Найти в проекте**) ищет `TypecraftText` в режиме *Localized* в открытых и
закрытых сценах и префабах `Assets/` и строки `"ключ"` в `.cs`. Одно место — сразу переход:
объект выделяется, закрытая сцена открывается после вопроса о сохранении, префаб открывается в
Prefab Mode, скрипт — на нужной строке. Несколько мест — список; клик по строке ведёт к месту.

### Задача: импорт из Google Sheets, Excel или CSV

Таблицу можно вести во внешнем файле и подтягивать в редакторе (в игре синхронизации нет).

**Формат.** Первая строка — заголовки: колонка `key` обязательна, `comment` — по желанию, остальные —
коды языков (`en`, `ru`, `zh-Hans`). Колонки, не похожие на код языка (`notes`), пропускаются.

**Один раз — «Импорт…».** Выбери `.csv`, `.tsv` или `.xlsx`; перед применением откроется отчёт.

**Постоянный источник — «Источник…».**

![Диалог «Источник синхронизации»](Images/localization-sync-source.png)

1. Выбери таблицу и нажми **Источник…**.
2. **Тип**: *Google Sheets*, *Excel* (`.xlsx`: файл и лист) или *CSV/TSV* (файл).
3. Для Google Sheets вставь обычную ссылку `https://docs.google.com/spreadsheets/d/<SHEET_ID>/edit#gid=<GID>` —
   лист берётся по `gid`. Таблице нужен доступ «Все, у кого есть ссылка — читатель» (или
   «Опубликовать в интернете»); закрытая даёт ошибку «Таблица закрыта».
4. **Сохранить** или **Сохранить и синхронизировать**. Источник хранится в
   `ProjectSettings/TypecraftTableSync.asset` (только редактор, в билд не попадает); ссылка попадает
   в репозиторий, поэтому не клади туда закрытые таблицы.
5. Дальше достаточно **Синхронизировать**. Загрузка идёт в фоне, её можно отменить кнопкой **Отмена**.

**Отчёт перед применением.**

![Отчёт синхронизации: новые ключи, «было / стало», потеря разметки](Images/localization-sync-report.png)

Вверху — сводка («новых ключей: 1, изменённых строк: 3»), затем предупреждения, переключатели и
разделы: **Новые ключи**, **Разметка перестанет применяться**, **Изменённые строки · язык** (с «было / стало»),
**Комментарии**, **Нет в источнике**.

- **Добавить языки** — если в источнике есть языки, которых нет в проекте.
- **Стирать строки…** — пустая ячейка в источнике по умолчанию **не стирает** перевод; флажок включает стирание.
- **Удалить ключи, которых нет в источнике** — по умолчанию выключено; при включении у ключей
  удаляется и разметка.
- **Применить** — одна операция Undo. После синхронизации используй фильтр **Только изменившиеся**
  и **Перенести теги**.

### Задача: экспорт

![Диалог экспорта](Images/localization-export.png)

1. **Экспорт…** → **Формат**: Excel `.xlsx`, CSV, TSV или JSON.
2. **Что выгрузить**: текущая таблица или все.
3. **Экспорт…** → выбери файл (для CSV/TSV всех таблиц — папку, файл на таблицу).

Колонки: `key`, `comment` и языки (основной первым) — файл читается обратно через синхронизацию.
В `.xlsx` шапка закреплена, пустой перевод залит красным, строка с ⚠ — оранжевым. Оформление из
слоя разметки в файл не попадает.

![Вкладка «Библиотека»: наборы иконок, стили, пресеты материалов, эффекты](Images/library-overview.png)

Слева — список: **Наборы иконок** (с числом картинок), **Стили**, **Пресеты материалов**,

### Наборы иконок

![Набор иконок: плитки и подсказка про перетаскивание](Images/library-iconset.png)

Набор — папка PNG, из которой собирается атлас и `TMP_SpriteAsset`. Плитка — одна иконка, подпись — её
ключ. Кнопки набора: **Пересобрать** (пересобрать атлас из папки исходников), **▸** (показать ассет),
**Папка** (открыть папку исходников).

#### Задача: добавить набор иконок и подогнать иконку

1. **+ набор иконок** → имя и родительская папка внутри `Assets` (не в `Resources`: исходные PNG попали бы в билд).
   Создаётся папка `<имя>/Source`, ассет набора и запись в `TypecraftSettings`.
2. Перетащи PNG из проводника или окна Project в окно набора — файл скопируется в `Source`, атлас
   пересоберётся. Ключ иконки берётся из имени файла.
3. Картинка проверяется на соответствие стандарту — 128×128, рисунок в центре, поля по 12 px
   ([`ART_RULES.ru.md`](ART_RULES.ru.md), шаблон [`IconTemplate_128.png`](IconTemplate_128.png)). Если что-то не так,
   откроется проверка:

   ![Проверка иконки при добавлении](Images/library-icon-check.png)

   В превью — иконка в строке с текстом и линии строки. **Всё равно добавить**, **Подогнать**
   (добавить и сразу открыть подгонку) или **Отмена**.
4. Клик по плитке открывает панель иконки:

   ![Подгонка иконки: смещение, масштаб, цвет текста](Images/library-icon-fit.png)

   - **Ключ** — тег (`{showcase/candle}` — со ссылкой на набор), переименование переписывает
     теги в таблицах, сценах и префабах;
   - **Смещение X / Y** и **Масштаб** — подгонка относительно строки; **Сдвиг набора по Y** — одна
     поправка на весь набор; **Сбросить иконку** возвращает значения по умолчанию;
   - **Красится цветом текста** — иконка берёт цвет окружающего текста;
   - **Копировать {…}** кладёт тег в буфер, **Удалить** убирает иконку из набора.
   - Внизу — превью в строке текста.
5. Нет картинки под ключ? Плитка-заглушка ждёт PNG с тем же именем.

### Стили

![Редактор стиля: поля и образец](Images/library-style.png)

Клик по стилю открывает его поля (те же, что в форме создания) и **образец** с живым превью.
**Дублировать** создаёт копию, **Удалить** убирает стиль. Поле **Слова автотега** задаёт слова,
которые оформляются этим стилем автоматически. Переименование **Id** переписывает теги в слоях,
таблицах и сценах (префабы и закрытые сцены сохраняются сразу, без Undo).

### Материалы и эффекты

Разделы **Пресеты материалов** и **Свои эффекты** показывают созданные в формах пресеты и эффекты;
**Удалить** убирает выбранный (материалы и эффекты уходят в корзину ОС, теги в тексте остаются).

## 5. Вкладка «Шрифты»

![Вкладка «Шрифты»: роли × языки, покрытие символов](Images/fonts-overview.png)

Таблица **роли × языки**: колонка «По умолчанию» и по колонке на язык. Роль — смысловая позиция
(`Body`, `Header`), звёздочка ★ — роль по умолчанию. В ячейке — шрифт языка для роли; пустая
ячейка наследует (`↳ LiberationSans SDF ✓` — какой шрифт реально применится).

Под ячейкой — покрытие символов: `✓`, либо **нет N** (N символов из строк языка нет в шрифте),
рядом **Пересобрать** для статического шрифта. Сводка в заголовке: `ячеек без символов: 2`.

**Панель:** **+ роль** (новая роль шрифта), **▸** (показать профиль), **⟳** (перепроверить покрытие).

Клик по названию роли раскрывает её материалы и переопределения по языкам:

![Роль «Body»: пресеты материалов и переопределения](Images/fonts-role.png)

### Задача: собрать шрифт для языка

Нужна для CJK и всех языков с большим алфавитом: статический шрифт содержит только символы,
которые встречаются в строках, и весит в разы меньше полного.

1. В блоке **«Статический шрифт по набору символов»** (слева внизу) укажи **Исходный шрифт**
   (TTF/OTF; для китайского подойдёт Noto Sans SC) и **Язык**.
2. По желанию — **Доп. символы**: текстовый файл с символами, которых нет в строках (имена, UI).
3. **Собрать и назначить**: пакет берёт из исходника только нужные символы (плюс ASCII и
   пунктуацию), строит `TMP_FontAsset` и назначает его всем ролям этого языка.
4. Добавили новые строки на этом языке — в ячейке роли появится **нет N**: нажми **Пересобрать**.
   Атлас в материалах пресетов обновится сам.

> В сэмпле Showcase китайский намеренно есть только у заголовка и подсказки: в проекте с
> существующим шрифтом zh-Hans рядом появится `нет N` — это штатный случай «нужно пересобрать».

## 6. Вкладка «Диалоги»

![Вкладка «Диалоги»: список, граф и инспектор](Images/dialogues-overview.png)

Раскладка вкладки:

- **Слева** — диалоги, говорящие и флаги проекта. Число справа от диалога — количество нод.
  Знак **+** у раздела создаёт новый элемент (флаг создаёт каталог, если его ещё нет).
- **В центре** — доска. **Граф**: нода — прямоугольник, связь — перетаскивание с выхода на вход,
  пробел или правый клик — новая нода, мини-карта слева сверху. Либо **Список** нод (переключатель
  «Граф/Список» справа на панели).
- **Справа** — инспектор выделенной ноды. Если ничего не выделено, показан сам диалог:
  путь, число нод и проблем.
- **Внизу** — панель с вкладками **▶ Проигрывание** и **Проблемы** (сворачивается стрелкой справа).
- **Панель** сверху: выбор диалога, таблица строк по умолчанию, **+ Нода**, **Проверить · N**,
  **▶ Проиграть**, вид доски и язык текстов.

Доску можно двигать средней кнопкой мыши и масштабировать колесом; связь рисуется
перетаскиванием с выхода на вход, **Delete** удаляет, **Ctrl+C / Ctrl+V / Ctrl+D** копируют и дублируют.

**Типы нод.** Старт, **Реплика** (говорящий, эмоция, ключ), **Выбор** (варианты с условием),
**Условие** (Branch — развилка), **Флаги** (Set Variables), **Событие**, **Ожидание**, **Переход**,
**Конец** — подробности в [README → «Диалоги»](../README.md).

### Задача: создать диалог

1. Вкладка **Диалоги** → **+** у раздела «Диалоги» — новый диалог; ассет появится в проекте.
2. В выпадающем списке на панели выбери **таблицу строк** диалога (в нашем примере `Showcase`).
3. Добавь ноды: **+ Нода** (на графе — пробел или правый клик) → *Реплика*, *Выбор*, *Условие*…
   Соединяй порты: перетащи точку с выхода одной ноды на вход другой. Все ноды без входящих
   связей, кроме Старта, подсвечиваются проверкой как недостижимые.
4. Создай **говорящих**: **+** у раздела «Говорящие» → `SpeakerProfile`. В ассете задай ключ имени,
   стиль имени, портреты по эмоциям (`neutral`, `angry`, `smile`…), сторону (*Left/Right*).
5. Создай **флаги**: **+** у раздела «Флаги» → имя, тип (`bool/int/float/string`), значение по
   умолчанию, описание.
6. Для каждой реплики заведи строку в таблице — см. «Создать ключ» ниже — и проверь диалог.

#### Инспектор реплики

![Инспектор реплики: говорящий, эмоция, ключ, варианты по условию](Images/dialogues-node-line.png)

- **Говорящий** и **Эмоция** — из списков (эмоции берутся из портретов говорящего).
- **Таблица** — по умолчанию таблица диалога; **Ключ** — поле с поиском, под ним текст на языке доски
  и превью с оформлением из слоя.
- **Создать ключ** — если такого ключа нет, впиши текст на основном языке и нажми кнопку: строка
  появится в таблице. Оформление `[стиль]` и `<тег>` из введённого текста уйдёт в слой разметки.
- **Переход дальше** — по нажатию, через N секунд или после печати + N секунд.
- **Варианты по условию** — другой ключ и эмоция, когда условие выполнено (берётся первый подходящий).
- **Переходы** внизу — на какую ноду ведёт «Далее» (стрелка → переходит к ней).

### Задача: добавить выбор с условием

![Инспектор ноды «Выбор»: варианты, условия, поведение «если недоступен»](Images/dialogues-node-choice.png)

1. **+ Нода → Выбор**; соедини вход с репликой, которая предлагает выбор.
2. В инспекторе **+ вариант**: укажи **Таблицу/Ключ** текста варианта.
3. **Доступен, если** — условие. Выбери флаг из списка, оператор (`истина`, `ложь`, `=`, `≠`, `>`, `≥`, `<`, `≤`) и
   значение; несколько условий объединяются **все (И)** или **любое (ИЛИ)** — переключатель рядом с заголовком.
4. **Если недоступен**: **Скрыть** — варианта не видно; **Показать неактивным** — виден серым и не нажимается.
5. Выведи выход варианта (порт «N. Название» на ноде) на нужную ноду — реплику, флаги или **Конец**.

В Showcase «Take the matches» скрывается после `has_matches = true`, «Light the lamp» виден серым, пока флага нет.

### Задача: проверить диалог

![Панель «Проблемы» диалога](Images/dialogues-problems.png)

**Проверить · N** (или вкладка **Проблемы**) показывает список: ошибки (красные) и предупреждения
(жёлтые). Клик по строке выделяет ноду. Проверяются: нет старта, пустые и битые связи,
недостижимые ноды, пустой или отсутствующий ключ, нет перевода, устаревшая разметка, нет
символа в шрифте, необъявленный флаг или не тот тип, неизвестная эмоция. **Проверить все** прогоняет все диалоги проекта.

В Showcase здесь 12 предупреждений «нет перевода на zh-Hans» — это сознательно: так видно, как
выглядит панель, а игра при отсутствии перевода показывает основной язык.

![Тот же диалог в виде списка](Images/dialogues-list.png)

Переключатель вида **Граф / Список** на панели показывает ту же последовательность списком: удобно
для длинных диалогов и когда граф недоступен (см. [«Без GraphView»](../README.md)).

### Задача: проиграть диалог без запуска игры

![Проигрывание в окне: портрет, печать, эффект, лог](Images/dialogues-playback.png)

1. Вкладка **▶ Проигрывание** → **▶ С начала** (или выдели ноду и **▶ С выделенной**).
2. Реплика печатается как в игре (флажок **Печать**; **⟲** — показать заново, **Пропустить ожидание** — не ждать таймер).
   Кнопка **Далее ▸** (или клик) переходит дальше; первое нажатие допечатывает текст.
3. Слева — **Флаги проигрывания**: меняй их на лету и смотри, как ветвится диалог; **Сбросить**
   возвращает значения из каталога и обнуляет посещения. Справа — **Лог**: ноды, условия, выборы.
4. Текущая нода подсвечивается на доске.

![Выбор в проигрывании: недоступный вариант серый](Images/dialogues-playback-choice.png)

На выборе показаны варианты: недоступный с поведением «Показать неактивным» серый и не нажимается.
**■ Стоп** останавливает проигрывание.

### Задача: подключить диалог в сцене

![Сцена Showcase: заголовок, подсказка, разметка, иконки, кнопки и окно диалога](Images/showcase-scene.png)

Минимальный набор объектов: выход (presenter), плеер и запуск.

1. **Выход.** `GameObject → Typecraft → Dialogue Box` (окно с портретами и кнопками выбора),
   `Subtitles` (строка `{имя}: реплика`) или `World Text` (текст в мире). Объект создаётся внутри
   `Canvas` и при необходимости заводит `EventSystem`.
2. **Плеер.** Добавь на пустой объект компонент `DialoguePlayer` и укажи:
   **Asset** — диалог (`Dialogue_Showcase`), **Presenter** — созданный выход. Если выход не умеет
   выбор — задай **Choice Presenter**. Включи `Play On Start`, если диалог должен идти сразу;
   `Once` — не играть повторно.
3. **Запуск.** Три способа:
   - `Play On Start` на плеере;
   - компонент `DialogueTrigger` (добавь на объект с коллайдером-триггером или на любой другой): режим
     `OnTriggerEnter` с тегом (например, `Player`), вручную `Fire()` или на старте;
   - из кода: `player.Play()` (и `Advance()`, `Choose(i)`, `Stop()`).
4. **Ввод «далее».** Для кнопки или клавиши на плеер добавь `DialogueInputAdvance`
   (сборка Input System) и укажи `InputActionReference`; либо вызывай `player.Advance()`.
5. **Флаги.** Положи каталог флагов в `DialogueGlobals.Catalog` (скриптом, как делает `ShowcaseSample`) —
   тогда флаги получат значения по умолчанию, а вкладка «Диалоги» увидит каталог сама.
6. **События.** Нода «Событие» вызывает `DialoguePlayer.OnEvent(name, argument)`. В Showcase
   `lamp / on` зажигает лампу.

Подробнее о компонентах и событиях — [`API.ru.md`](API.ru.md).

## Демо-сэмпл Showcase

Сэмпл — всё, что показано на скриншотах: сцена со стилями, иконками, подсказкой ввода и эффектом,
диалог «Смотритель маяка» с ветвлением, выбором и условиями, два говорящих с портретами, каталог

### Как импортировать

1. В проекте должен быть `TypecraftSettings` (`Tools/Typecraft/Create Project Settings`) со встроенными
   таблицами строк (`TableTextSource`). Для эффектов — TMPEffects, для глифа кнопки — Input System.
2. `Package Manager → Typecraft → Samples → Showcase → Import`.
3. `Tools/Typecraft/Samples/Connect Showcase Table` — подключает таблицу `Showcase` к источнику строк, слой
   разметки и набор иконок — к `TypecraftSettings`, добавляет языки `en`, `ru`, `zh-Hans`.
   Обратно: `Tools/Typecraft/Samples/Disconnect Showcase Table`.
4. Открой `Showcase.unity`, нажми Play: **Talk to the keeper**, **Next** или пробел (первое нажатие
   допечатывает реплику), **Language** переключает язык.

В проекте со Zenject/своим стартовым сценарием Play может сначала загрузить стартовую сцену проекта — открой
`Showcase.unity` в режиме Play именно как стартовую или загрузи её из кода.

### Сценарий для знакомства с окном

1. Вкладка **Локализация**, таблица `Showcase`: найди строки с `∅`, `⚠`, `□`; выдели `ui.stale` и нажми **Перенести теги**.
2. Выдели в сцене объект `Hint` — вкладка **Редактор** покажет подсказку со стилем, глифом и иконкой; сменой **KBM / Xbox / PS**
   проверь глиф.
3. **Библиотека → showcase**: подгони иконку `lamp`.
4. **Диалоги → Dialogue_Showcase**: **▶ С начала**, пройди разговор, включи `has_matches` в «Флагах проигрывания» и посмотри,
   как оживает «Light the lamp».
5. Play: сыграй диалог в сцене; событие `lamp / on` зажигает лампу.

Если после импорта вместо текста видны ключи (`ui.hint`), таблица не подключена — шаг 3.

## 8. Если что-то не так

| Симптом | Причина и что делать |
| --- | --- |
| Вместо текста виден ключ | Таблица или слой не подключены к `TypecraftSettings` (для сэмпла — `Connect Showcase Table`) |
| Нет курсива, цвета и дрожи | Не подключён слой разметки, либо строку в таблице поменяли: ⚠ → **Перенести теги** |
| Квадраты вместо иероглифов | Статический шрифт собран под другие строки: вкладка «Шрифты» → **Пересобрать** |
| Теги `<wave>` видны буквально в превью | Не установлен TMPEffects; если он есть — переключи ❚❚/▶ или перевыдели объект, превью обновится |
| Вместо кнопки красный `[Interact]` | В `InputGlyphProfile` нет действия `Interact` — замени ключ на своё действие |
| Вкладка «Диалоги» открывается списком | Нет сборки графа (`Editor.Dialogue.Graph`) или включён define `TYPECRAFT_NO_DIALOGUE_GRAPH` — всё остальное работает |
