# Правила для картинок внутри текста

Иконка в строке текста — это глиф, как буква. Она должна стоять на той же базовой линии,
что и соседние буквы, и не «прыгать» при смене набора (клавиатура → геймпад). Правила ниже
ровно про это.

## Холст

- Стандарт: квадрат **128×128 px**, PNG с прозрачностью (8 бит на канал, без премультипликации альфы).
- Рисунок — в центральной области **104×104 px**: поле 12 px с каждой стороны остаётся пустым.
  В поле не должно быть ни обводки, ни тени, ни свечения (проверка считает пиксель занятым
  при альфе больше ~0.05).
- Одинаковый холст у всех иконок набора. Разные размеры внутри набора = разная высота в строке.
- Базовые наборы пакета нарисованы на других холстах (100 px и крупнее) — это допустимо:
  размер сравнивается с преобладающим внутри набора, а не с 128.
- Шаблон: `Documentation~/IconTemplate_128.png` — синий контур границы полей, красная линия
  низа рисунка, пример фигуры внутри.

## Опорная точка и базовая линия

- Опорная точка иконки в тексте — **левый нижний угол холста**. Низ холста стоит ровно на базовой
  линии строки, иконка начинается там, где кончился предыдущий символ, и занимает в строке
  ширину холста. Пивот спрайта на положение в тексте не влияет.
- Высоту холста TMP подгоняет под линию ascent шрифта (верх строки над базовой линией), поэтому поле 12 px
  даёт одинаковый воздух вокруг иконки при любом размере шрифта.
- Если рисунок должен опускаться ниже строки (как буквы `g`, `y`) — это ручная подгонка,
  а не смещение рисунка внутри холста.

## Проверка при добавлении

При перетаскивании PNG в набор (вкладка «Библиотека») картинка проверяется: квадрат ли она,
совпадает ли размер с преобладающим в наборе, не заходит ли рисунок в поля. Если что-то не так,
открывается окно с причинами и превью иконки внутри строки текста:

- «Всё равно добавить» — добавить как есть;
- «Подогнать» — добавить и сразу открыть ползунки подгонки этой иконки;
- «Отмена» — не добавлять.

При пересборке набора (кнопка «Пересобрать», `Rebuild Atlas`, `Rebuild Base Prompt Sets`) те же
проверки только пишут предупреждение в консоль.

## Ручная подгонка

Без пересборки атласа, в панели набора (вкладка «Библиотека» → набор → иконка):

- **Смещение X / Y** иконки — доля высоты иконки; плюс сдвигает вправо и вверх.
- **Масштаб** иконки — от левого нижнего угла, по умолчанию 1. Вместе с иконкой растёт и место,
  которое она занимает в строке.
- **Сдвиг набора по Y** — общий для всех иконок набора (`IconSet → Build Settings → Vertical Offset`),
  складывается со смещением иконки.

Превью под ползунками показывает строку с иконкой: красная линия — базовая, серые — верх
и низ строки.

## Правильно и неправильно

- Правильно: холст 128×128, кнопка нарисована в центре и занимает почти всю область 104×104,
  по 12 px прозрачного поля вокруг. В строке низ кнопки стоит на базовой линии, рядом с буквами,
  без наползания на соседние слова.
- Неправильно: рисунок прижат к краям холста, тень уходит в поле — иконка в строке
  слипается с соседними буквами.
- Неправильно: холст 128×96 — иконка растягивается по высоте строки и выглядит сплющенной
  или вытянутой относительно соседних.
- Неправильно: рисунок нарисован в нижней половине холста, «чтобы сел на строку» — иконка
  окажется ниже соседних. Положение в строке правится подгонкой, а не картинкой.

## Цвет

Два вида иконок, и каждый набор держит только один вид:

- **Перекрашиваемые** — белый силуэт на прозрачном. Цвет приходит из текста (`<color>`,
  стиль). Флаг `Tintable` у записи.
- **Полноцветные** — готовая картинка, цвет текста на неё не влияет.

## Имена и ключи

- Имя файла = имя глифа в атласе. Латиница, цифры, `_`. Без пробелов и кириллицы.
- Ключ в тексте строится из имени автоматически: общий для набора префикс и суффикс
  срезаются, остальное в нижнем регистре. `PS5_Cross.png` → `cross`, `A_Key_Dark.png` → `a`.
- Ключ можно завести заранее, без картинки: запись-заглушка в `IconSet`. Текст с ней
  собирается, окно Typecraft подсвечивает её как «нет арта».
- Переименование файла не ломает тексты, пока ключ записи остаётся прежним.

## Где лежит

- Исходники — в папке, имя которой кончается на `~` (Unity такие папки не импортирует):
  исходник никогда не попадает в билд и не тратит время импорта.
- Сгенерированный атлас и `TMP_SpriteAsset` лежат рядом с ассетом `IconSet`.
- Пересборка: правая кнопка по `IconSet` → `Rebuild Atlas`. Базовые наборы пакета —
  `Tools → Typecraft → Rebuild Base Prompt Sets`.

## Мобилки

- Атлас без мипмапов и без сжатия: иконки мелкие, артефакты сжатия на них заметны сильнее,
  чем выигрыш по памяти.
- Один набор — один атлас, до 2048 px. Больше — делить набор.
